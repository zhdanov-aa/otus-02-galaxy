Агент передаёт в игровой сервис сообщение в формате JSON:

```
{
    "game_id": "256",
	"object_id": "512",
	"command_id": "move"
}
```

Где:

|Ключ|Тип|Назначение|
|---|---|---|
|`game_id`|строка|Идентификатор игры к которой относится сообщение|
|`object_id`|строка|Идентификатор объекта игры к которому относится команда|
|`command_id`|строка|Команда передаваемая объекту игры|

В зависимости от значения ключа `command_id` сообщение может содержать дополнительные ключи описывающие аргументы команды.
